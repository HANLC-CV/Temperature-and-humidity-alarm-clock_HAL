## 主要功能
```text
├── 定时闹钟：支持用户设定多个定时闹钟，到达设定时间时自动响铃提醒。
├── 温湿度显示：通过传感器实时采集并在LED灯板上显示当前环境的温度与湿度，温度支持摄氏度与华氏度切换。
├── 音乐欣赏：支持简单的背景音乐播放功能，用于闹钟铃声或用户自行欣赏。       
├── 声控显示：系统可通过声响（如拍手、说话）唤醒显示屏，节能同时提升交互体验。        
├── 亮度调节：支持根据环境光强或用户设置调整屏幕亮度，提高可读性并降低能耗。
├── 按键控制：通过实体按键进行时间设置、闹钟设置、功能切换等操作，使用方便。
```

## 系统架构

系统主要由以下部分组成：
```text
STM32
│
├── Application---FreeRTOS
     ├── 时间、温湿度采集任务
     ├── 时间、温湿度显示任务
     ├── 按键处理任务
     ├── 闹钟控制任务
     └── 音频播放任务          
├── Common
     ├── Common_test  串口调试         
└── Interface
     ├── DHT11  温湿度采集模块
     ├── NV020D  语音播放芯片，用于闹钟提示音及系统音频输出
     ├── DS1302z  实时时钟芯片，用于日期和时间计时，并为闹钟功能提供时间基准
     ├── Key  拨动开关、触摸开关、按键开关状态获取
     ├── Mic  外部音量检测
     └── Led  灯板的LED控制
```
